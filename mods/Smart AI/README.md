# Smart AI — ИИ-командир для LuaAPI

Мод не строит базу за движок и не заказывает юнитов: этим по-прежнему занимается
RA2. Smart AI работает как штаб — каждый скан он смотрит, что у каждого ИИ-дома
есть, и постоянно отдаёт приказы `Attack` на конкретные здания врага.

Главная проблема ванильного ИИ, ради которой всё это: в логах телеметрии Hard-ИИ
копит 30–50 юнитов у базы и не идёт в атаку (команды `team_new` создаются с
`members=0`, цели нет). Мод заставляет эти же юниты воевать.

## Что делает

* считает по каждому дому здания и юниты (`World.GetBuildings/GetUnits`);
* выбирает самого слабого врага (меньше всего зданий), а в нём — цель по
  приоритету: МСЦ/стройплощадка, потом завод, переработчик, энергия;
* повторяет приказ `Attack` каждые 90 кадров, чтобы движок не увёл юнитов;
* треть армии отправляет сносить турели у цели (иначе волна разбивается о
  `GAPILL`/`NASAM`/`TESLA`);
* держит экономику: +4000 кредитов всем ИИ-домам раз в 600 кадров;
* ведёт артиллерийскую подготовку (`TakeDamage` по обороне у цели, затем по
  самой цели), когда у дома набралось 10+ боевых юнитов;
* игрока и наблюдателя не трогает вообще — они исключены из выбора цели.

## Стили фракций

| Фракция | Как воюет |
| --- | --- |
| Allied (`Americans`, `British`, `French`, `Germans`, `Alliance`) | ждёт группу из 5, держит 2 юнита в обороне, бьёт по производству (завод/МСЦ) |
| Soviet (`Russians`, `Africans`, `Arabs`, `Confederation`, `Iraqis`) | идёт в атаку с 3 юнитов, обороны дома не держит, первым делом рудокопы и переработчики |
| Yuri (`YuriCountry`) | держит 1 юнита в обороне, глушит оборону `Disable` (только техника и пехота), бьёт по энергетике и экономике |

## Как посмотреть матч ИИ против ИИ

Отдельного лаунчера нет. Матч-наблюдатель поднимает тестовый стенд:

```
cd D:\Games\Red Alert 2 LuaAPI\Asolated
python .freebuff\selfplay.py --map 4_bull_run_le --ai 3 --diff 0 --seconds 600 --keep-open
```

* `--diff 0` — Hard (в spawn.ini это `HandicapDifficulty`, у него обратная
  шкала: 0 = Hard, 1 = Normal, 2 = Easy);
* `--ai 3` — три ИИ, сложность Hard, игрок = чистый наблюдатель
  (`IsSpectator=True`, `Side=0`);
* `--keep-open` — не закрывать игру по таймеру, матч останется на экране;
* без `--keep-open` стенд сам закрывает игру и печатает сводку по домам.

Стенд пишет `spawn.ini`, запускает `Syringe.exe`, внедряет `LuaAPI.dll` в живой
`gamemd-spawn.exe` и читает телеметрию `mods/AI Telemetry/logs/*.jsonl`.

## Логи

* `LuaAPI.log` — строки `[SMARTAI]`: дома в матче, «в атаку N, цель TYPE»,
  «дом уничтожен: X», «матч решён, остался X», сводка по домам.
* `mods/AI Telemetry/logs/match-*.jsonl` — здания, юниты, потери, группы.
* `Asolated\.freebuff\attack_report.py` — сводка по атакам из JSONL.

## Известные ограничения

* `house:SpawnUnit` — отладочный API. Он умеет только технику (пехота для него
  неизвестный `typeId`), а на узких картах (например `4_caverns`) создание юнита
  валит игру с `C0000005`. Поэтому мод **не спавнит юнитов**: раньше на спавне
  ИИ уничтожали друг друга за 30–50 с, но стабильности не было.
* `unit:SetHealthRatio` (полевой ремонт) тоже роняет игру при массовых вызовах —
  не используется.
* `ltnk_emp_nerf` конфликтует с любым ИИ-командиром: мод каждые ~70 мс
  парализует половину Lasher-танков, командир их снова отправляет в атаку, в
  логе тысячи `EMP Lock` и игра падает. С Smart AI этот мод лучше выключить.
* Ares на этой сборке сам по себе изредка падает с `C0000005`; после падения
  причина видна в `except.txt` и `debug\snapshot-*`.
